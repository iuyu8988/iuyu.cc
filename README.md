# IUYU (이유) — 실리콘 보호케이스 OEM/ODM 제조사 사이트

전자담배 기기용 실리콘 보호케이스·파우치를 만드는 **B2B 제조사** 사이트.
한국어 / English / 中文 3개 언어, 정적 배포, 검색엔진 최적화 포함.

- Next.js 14 (App Router, `output: 'export'`) — `out/` 을 아무 정적 호스팅에 올리면 끝
- 디자인 컨셉: **「정밀 도면(Precision Drawing)」** — 금형 제조사의 실제 작업 언어(치수 기입, 좌표 격자, 부품 번호, 공차)를 화면 언어로 옮김
- 33 페이지 = 11 경로 × 3 언어

## 디자인 시스템

### 컨셉: 정밀 도면

실리콘 금형 제조사가 실제로 쓰는 시각 언어를 그대로 화면에 옮겼습니다. 장식이 아니라 업(業)의 표현입니다.

| 요소 | 구현 | 위치 |
| --- | --- | --- |
| 도면 표제란 | `SHEET 01 / 08`, `REV.`, `SCALE 1:1` | 히어로 상단, 각 내부 페이지 |
| 좌표 격자 | 48px / 16px / 32px 격자, 5.5% 농도 | 배경, 제품 스테이지 |
| 치수 기입 | 실제로 그려지는 치수선 + 실측값 | 히어로 제품, 공정 |
| 좌표 마커 | 원 + 십자 | 제품 스테이지 4모서리 |
| 부품표 | 모노스페이스 번호 + 항목 | 역량 카드, 스펙 |
| 도판(plate) 번호 | `PLATE 01` | 제품 갤러리 |

### 타이포그래피

**유체 스케일**(`clamp()`)로 320px~1600px 구간에서 자연스럽게 확대됩니다. 세 언어의 글자 수 차이(한국어 10자 / 영어 최장 26자 / 중국어 7자)를 모두 한 줄에 수용하도록 값을 잡았습니다.

| 토큰 | 값 | 용도 |
| --- | --- | --- |
| `--fs-display` | `clamp(1.95rem, 3.85vw, 3.6rem)` | 히어로 주장 |
| `--fs-h1` | `clamp(1.7rem, 3.4vw, 3rem)` | 섹션 대제목 |
| `--fs-h2` | `clamp(1.45rem, 3vw, 2.25rem)` | 보조 섹션 |
| `--fs-micro` | `0.6875rem` (11px) | 도면 주기 라벨 하한 |

한국어는 자간을 좁히고(`-0.035em`), 라틴 대문자 라벨은 넓혔습니다(`+0.16em`). 숫자는 전부 등폭(`tabular-nums`)이라 표에서 자릿수가 흔들리지 않습니다.

### 색

| 토큰 | 값 | 대비비(paper) | 용도 |
| --- | --- | --- | --- |
| `--paper` | `#f2f3f5` | — | 페이지 바닥 |
| `--surface` | `#ffffff` | — | 카드 |
| `--ink` | `#0b0e12` | 17.42 | 제목 |
| `--ink-2` | `#3a424c` | 9.17 | 본문 |
| `--ink-3` | `#5d666f` | 5.26 | 보조 |
| `--ink-4` | `#78818b` | 3.56 | 도면 라벨 |
| `--accent` | `#0d6b76` | 5.59 | 강조 (제품 실사에서 추출) |
| `--accent-on-dark` | `#5fd0e0` | 10.67 (vs #0b0e12) | 어두운 밴드 전용 |

**강조색은 딱 한 색**입니다. 제조사 사이트에서 색이 여러 개면 신뢰감이 떨어집니다.

### 배경이 제품과 연결되는 방식

배경은 임의의 그라데이션이 아니라 **제품 실사에서 추출**했습니다. `scripts/gen_assets.py` 가 무지 실리콘 표면에서 채취합니다(화면 아트워크 영역에서 채취하면 배경에 문자·캐릭터가 비쳐 나오므로 금지).

| 파일 | 채취 원본 | 사용처 |
| --- | --- | --- |
| `tex-silicone-matte.jpg` | 닫힌 케이스의 무지 실리콘 면 | 페이지 배경, 히어로, CTA |
| `tex-brushed-metal.jpg` | 목걸이끈 코드의 무광 질감 | 소재 섹션, 마감 옵션 |

### 동작

| 요소 | 구현 |
| --- | --- |
| 스크롤 리빌 | 3종: `rise`(이동) / `unmask`(클립이 걷힘) / `fade` |
| 치수선 | IntersectionObserver 로 좌→우 / 상→하 그려짐 |
| 마퀴 | 공정 키워드 무한 흐름 (42s linear) |
| 스포트라이트 | 커서 추적 radial-gradient (`--mx/--my`) |
| 링크 밑줄 | `scaleX` 로 그려지는 애니메이션 |
| 버튼 채움 | 왼→오 배경 채움 + 텍스트 색 반전 |
| 스크롤 진행률 | 헤더 하단 1px 선 |
| 프로세스 타임라인 | 호버/포커스 시 진행선이 해당 단계까지 채워짐 |
| 제품 부유 | 9s 주기 `floatY` |
| 시차 | 마우스 + 스크롤 결합, 레이어별 이동량 차등 |

모든 애니메이션은 `transform` / `opacity` / `clip-path` 만 사용합니다(CLS 0). `prefers-reduced-motion` 을 존중하며, **IntersectionObserver 가 어떤 이유로든 발동하지 않으면 2.5초 후 강제 표시**하는 안전망이 있습니다(앵커 진입·백그라운드 탭·인쇄에서 콘텐츠가 영구히 숨는 것을 방지).

## ⚠️ 제품 실측값은 사진에서 읽었습니다

원본 사진에 **제조사가 인쇄한 치수 주석**이 들어 있었고, 그 값을 그대로 옮겼습니다.

| 항목 | 값 |
| --- | --- |
| 본체 | 96 × 53.5 × 29 mm |
| 마우스피스 커버 | 15 × 25 × 14 mm |
| 전체 높이 | 111 mm (마우스피스 포함) |
| 목걸이끈 | 44 cm |

이 값은 `content/dictionaries/*.ts` 의 `hero.dimW/dimH/dimTotal` 과 `pages.capabilities.specTable` 에 있습니다.

**사진에 인쇄된 중국어 주석과 지시선은 제거했습니다.** 3개 언어 사이트에 중국어가 박힌 이미지를 쓸 수 없고, 지시선이 남으면 아무것도 가리키지 않는 화살표가 되기 때문입니다. 치수는 HTML 치수선으로 다시 그립니다. 제거 좌표는 `scripts/gen_assets.py` 의 `ANNOTATION_BOXES` 에 있고, **원본을 교체하면 이 좌표를 다시 잡아야 합니다.**

## 3개 언어 구조

한국어가 기본 언어라 **접두사 없이** 서비스합니다(한국 사이트 관행, 기본 언어 중복 URL 방지).

| 언어 | URL | `<html lang>` | hreflang |
| --- | --- | --- | --- |
| 한국어 (기본) | `/` `/about/` … | `ko` | `ko-KR` |
| English | `/en/` `/en/about/` … | `en` | `en` |
| 中文 | `/zh/` `/zh/about/` … | `zh-Hans` | `zh-Hans` |
| — | — | — | `x-default` → 한국어 |

언어를 바꿔도 **같은 페이지에 머뭅니다** (`/en/oem/` → `/zh/oem/`). 전환기는 헤더 우측 상단.

```
app/
├─ layout.tsx              # 유일한 <html>/<body>, 스타일 링크, HtmlLang 보정
├─ (ko)/                   # 한국어 라우트 그룹 (URL 접두사 없음)
├─ [locale]/               # en / zh (generateStaticParams 에서 ko 제외)
├─ sitemap.ts  robots.ts  not-found.tsx
lib/i18n.ts                # LOCALES / localePath / alternatesFor
content/
├─ dictionaries/{ko,en,zh}.ts   # ★ 전체 문구 (228 key, 3개 구조 동일)
├─ legal-bodies.ts              # 정책 5종 × 3개 언어
└─ brand.ts                     # 언어 무관 (회사명·연락처·사업자 정보)
```

문구는 **`content/dictionaries/*.ts` 만 수정**하면 됩니다. `Dictionary` 타입이 `ko.ts` 에서 추론되므로 다른 언어에 키가 빠지면 컴파일이 실패합니다.

**언어 추가 3단계**: ① `lib/i18n.ts` 의 `LOCALES`/`LOCALE_META` 에 추가 → ② `content/dictionaries/` 에 사전 파일 복사·번역 → ③ `content/legal-bodies.ts` 에 정책 본문 추가.

### ⚠️ 사진을 추가·교체할 때 반드시 지킬 것

**1. 재직자 얼굴은 반드시 처리하세요.**

이미지에 포함된 사람 얼굴은 초상권 문제가 됩니다. 해외 바이어는 인권·노동 실사
(audit) 관점에서도 봅니다. 두 가지 방법이 있습니다:

- `scripts/prepare-photos.py` 의 `PHOTOS` 설정에 `"faces": "auto"` 를 넣으면
  DNN(다중 스케일) + Haar(정면·측면) 로 검출해 픽셀화합니다.
- **단, 사람이 많은 사진(10명 이상)에서는 자동 검출을 신뢰하지 마세요.**
  무진복 모자·마스크 때문에 누락이 생기고, 누락은 곧 개인정보 사고입니다.
  사람이 많은 컷은 아예 쓰지 않거나, 포토샵으로 직접 처리하세요.

**처리 후 반드시 눈으로 확인하세요.** 자동 검출은 "놓친 얼굴"을 스스로 알려주지 않습니다.

**2. 제3자 브랜드를 지우세요.**

공장 사진에는 남의 브랜드가 자주 찍힙니다. 이 사이트에서는:
- 모니터 뒷면 **Apple 로고** → 주변 금속면을 복제해 덮음 (설정의 `brands` 좌표)
- 파란周转箱의 **KCT 각인** → 색상 자동 검출로 제거 (`kct: true`)

Apple 로고를 남기면 무상 광고가 되고, KCT 각인이 남으면 "이게 누구 공장이냐"는
혼란을 줍니다. 좌표는 `prepare-photos.py` 에서 사진별로 지정합니다.

**3. 문구로 고지하세요.**

섹션 하단에 "재직자의 얼굴은 초상권 보호를 위해 처리했습니다" 문구가 3개 언어로
들어가 있습니다(`factory.note`). 이 문구를 지우지 마세요. 사진을 처리했다는 사실을
밝히는 것이 오히려 신뢰를 높입니다.

### 처리 스크립트

```bash
# .incoming/ 에 원본을 넣고
python3 .incoming/prepare_photos.py
```

`prepare_photos.py` 안의 `PHOTOS` 딕셔너리에서 사진별로 지정합니다:

| 키 | 의미 |
| --- | --- |
| `faces` | `"auto"` = 자동 검출 후 픽셀화, `"none"` = 인물 없음 |
| `brands` | 지울 제3자 브랜드 영역 `[(x0,y0,x1,y1), ...]` |
| `kct` | 파란 통의 KCT 각인 자동 제거 여부 (목재 선반이 있는 실내는 `False`) |
| `crop` | 사진 전체에서 잘라낼 영역 |
| `max_w` / `quality` | 출력 폭 / JPEG 품질 |

### 왜 어떤 사진은 뺐나

원본 9장 중 **3장을 제외**했습니다:

- **조립 라인 전면(12명)** · **포장 공정(6명)** — 사람이 밀집해 자동 얼굴 마스킹이
  실패했습니다(마스크 32개가 지면·의자에 찍히고 얼굴은 그대로 노출).
  수동 좌표로도 다수 인원을 정확히 덮기 어려워 사용하지 않았습니다.
- **생산동 통로** — 파란 통에 KCT 각인이 6곳 이상 반복 인쇄되어 개별 제거가
  지저분해졌고, 크롭으로도 완전히 피할 수 없었습니다.

즉 **6장은 완전히 깨끗하고, 3장은 사용하지 않았습니다.** 남은 3장을 쓰려면
포토샵 등으로 직접 얼굴과 각인을 처리한 뒤 `.incoming/` 에 넣어주세요.

## 이미지 자산

```bash
npm run assets                         # 원본 기준 전체 재생성
python3 scripts/gen_assets.py 새사진.png
python3 scripts/gen_assets.py --debug   # 크롭 결과를 /tmp/debug_*.png 로 확인
```

### 파이프라인이 하는 일

1. **주석 제거** — 사진에 인쇄된 중국어 치수 텍스트와 지시선·화살표를 지웁니다.
   3개 언어 사이트에 중국어가 박힌 이미지를 쓸 수 없고, 지시선이 남으면
   아무것도 가리키지 않는 화살표가 됩니다.
2. **흰 배경 → 소프트 알파** — 제품 가장자리 안티에일리어싱을 유지합니다.
3. **타이트 크롭** — 구성요소별로 실제 범위만.
4. **OG 카드 / 아이콘 / 배경 텍스처** 생성.

### ⚠️ 원본 사진의 구조적 한계

이 실사는 **한 장에 여러 구성요소가 배치된 합성 컷**입니다. 그래서:

- **오픈 케이스와 클로즈드 케이스는 분리할 수 없습니다.** 사진에서 x≈965 지점에서
  서로 맞닿아 있어, 사각형으로 자르면 반드시 이웃 조각이 섞입니다.
  그래서 개별 컷 대신 `hero-product.png` 로 함께 사용합니다.
- 결과적으로 **각도별 컷이 부족합니다.** 같은 각도에서 나온 변주이므로
  갤러리가 "여러 각도"가 아니라 "여러 구성요소"를 보여주는 형태입니다.

### 개선하려면

**빈 화면 상태의 단독 제품컷**을 각도별로 4~6장 촬영하면 갤러리 품질이 크게 올라갑니다:

| 권장 컷 | 용도 |
| --- | --- |
| 정면 (빈 화면, 45°) | 히어로 |
| 측면 프로파일 | 두께 강조 |
| 상단 (마우스피스 개방) | 구조 설명 |
| 하단 (충전 단자) | 기능 설명 |
| 목걸이끈 착용 | 사용 맥락 |
| 매크로 (실리콘 표면) | 소재 섹션 |

사진을 추가하면 `CROPS` 에 항목을 넣고 사전의 `views` 만 갱신하면 됩니다.
치수는 사진에 굽지 않고 HTML 치수선으로 그리므로, 원본을 교체해도
`hero.dimW/dimH/dimTotal` 값만 확인하면 됩니다.
